# Manual de usuario — MetaSoft Directory

## 1. Introducción

MetaSoft Directory permite consultar casas desarrolladoras de software, importar información desde sitios web oficiales, guardar fichas personales y exportar reportes PDF.

## 2. Acceso

1. Abre la aplicación en el navegador (por defecto http://localhost:5173).
2. Puedes **explorar el directorio** sin cuenta.
3. Para **guardar, publicar, favoritos o importar con persistencia**, ve a **Entrar** y regístrate.

## 3. Inicio

La página de inicio explica el sistema y muestra un aviso: el espacio personal requiere registro.

## 4. Directorio global

1. Entra a **Directorio**.
2. Escribe parte del nombre y pulsa **Buscar**.
3. Cada ficha muestra logo, especialidad, dirección, teléfono, descripción corta y categoría.
4. **Clic en el logo/imagen** abre el sitio oficial (si existe).
5. Menú **⋮** → **Guardar en Favoritos** (requiere sesión).
6. Marca varias fichas y usa **Exportar PDF**.

## 5. Categorías

- **Datos completos**
- **Datos parciales** (al menos un dato relevante)
- **Sin datos registrados**

## 6. Importar página

1. Inicia sesión.
2. Pega una URL https del sitio a analizar.
3. Revisa la vista previa.
4. Opciones:
   - **Descartar** — cierra sin guardar.
   - **Editar / corregir** — aviso: se etiqueta como modificado manualmente y **no podrá publicarse**.
   - **Guardar PDF** — descarga un PDF profesional de la vista previa.
   - **Guardar ▾**
     - Solo para mí
     - Para mí y publicar
     - Solo publicar

## 7. Mis Extracciones

- Pestaña **Personales**: tus fichas guardadas; selección múltiple → PDF.
- Pestaña **Favoritos**: accesos guardados desde el menú ⋮.

## 8. CRUD (Administración)

Con sesión activa puedes crear, editar y eliminar casas del directorio global. Las ediciones se marcan como modificadas manualmente.

## 9. Buenas prácticas

- Verifica que el enlace importado sea el sitio oficial.
- No publiques datos personales de terceros sin autorización.
- Si editaste a mano, usa solo guardado personal.
